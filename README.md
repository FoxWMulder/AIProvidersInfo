### Настройки

Настройки хранятся в файле "options.ini". Инструкция по настройкам в "Help\Options help.md".

### Создание свеого списка

По-умолчанию программа отображает информацию о всех моделях доустпынх у plusvibeapi.ru
Можно создать свой список моделей по которым будет отображатся информация.
Для этого в папке с программой нужно создать файл "models.txt".
Пример заполнения этого файла:

```
deepseek-v4-flash-0731:free
gpt-5.6-sol
gpt-5.6-terra
gpt-5.6-luna
```

По одной модели на строку. Название модели поулчать таким образом:
1) Открыть https://plusvibeapi.ru/models
2) Открыть информацию о конкретной модели. На примере GPT-5.6 Luna, в адресной строке будет "https://plusvibeapi.ru/model/gpt-5.6-luna".
3) Вот то что после последнего слеша и надо указывать в файле "models.txt".
